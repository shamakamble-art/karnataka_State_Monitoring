Sheet won't load? Two ways to fix it

Best fix — a published link. In the sheet: File → Share → Publish to web → pick the sheet, choose Comma-separated values (.csv) → Publish. Paste the link it gives you here. It works from anywhere, with no sign-in.

Or paste the cells. Select the whole grid in the sheet, header row included, copy, and paste it here.

Blocks come from a second tab. If block counts show a dash, publish Stakeholder_Details the same way and paste its link here, or copy that whole tab (header row included) into the box below.

Where the numbers come from. Every load, this page reads the live sheet and matches columns by their header text, not by position — so you can add, move or rename columns and it keeps working, as long as the header still contains the words it looks for: district, division, POC, calendar, CRP workshop, DIET, BRP, CRP interview, morning assembly and school visit. All the morning-assembly and school-visit columns are picked up automatically, however many there are. A cell counts as done when it has anything in it other than blank, no, pending, not done, NA, FALSE or 0. The calendar column is read as three states instead of two: blank is not done, In Process (also in progress, ongoing, started) shows amber, and anything else counts as done. A district still in process scores nothing towards its overall percentage until it is actually done.

If the status light is red, the page almost certainly isn't being served from a web address. Opening an HTML file straight from your computer puts the browser in its most restricted mode and it blocks the request to Google. Put the page on a web host and the same file works. The sheet itself is already shared as "anyone with the link", so no sign-in is needed. Nothing is ever written back to the sheet — this page only reads.

How the 34 boundaries were built. Karnataka has 31 revenue districts but 34 educational districts. Belagavi splits into Belagavi and Chikkodi, Uttara Kannada into Sirsi and Kumta, Tumakuru into Tumakuru and Madhugiri, Bengaluru Urban into Bengaluru U North and U South; Ballari and Vijayanagara are shown as the single unit your sheet uses. Each shape is the union of its taluks, dissolved from LGD/Survey of India subdistrict boundaries. Two things worth confirming with the DDPI lists: Vijayanagara now appears as its own DDPI district in state recruitment notices, and Bengaluru East taluk sits under Bengaluru U South here, following the department's own school directory.
